# Security Policy

WITMO is currently in early development. Please report security vulnerabilities privately to the repository owner instead of publishing technical details in a public issue.

A report should include the expected impact, reproduction steps, and a suggested mitigation when possible. Do not include active API keys, access tokens, user data, or other secrets in the report.

Only the latest version on the default branch is currently supported. After confirming a vulnerability, the repository owner will coordinate the remediation and disclosure timeline with the reporter.
